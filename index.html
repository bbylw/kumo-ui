Kumo 使得构建无障碍应用变得简单。它自动处理键盘导航、焦点管理和 ARIA 属性，让开发者可以专注于业务逻辑，而无需深究每一个无障碍细节。

01. 更新亮点

站点已同步至 @cloudflare/kumo 2.17.0（2026-11-02）。以下是当前版本的主要能力。

49 个组件 · 40 个原语

覆盖表单、导航、浮层、数据展示与布局。所有 Base UI 原语都可以从 @cloudflare/kumo/primitives/* 按需导入。

Blocks 按需安装

PageHeader、ResourceList、DeleteResource 等页面级区块通过 kumo add 写入项目，不随包入口捆绑。

AI 友好

内置 ai/component-registry、ai/schemas 与 kumo ai 命令，让编码 Agent 准确查询组件 API 与示例。

Tailwind v4 主题

语义颜色令牌基于 light-dark() 自动切换深浅色；非 Tailwind 项目可直接使用 styles/standalone。

可选依赖

Chart 需要 echarts，AI Schemas 需要 zod；两者均为可选 peer，不增加默认安装体积。

Figma 插件

构建时可选同步设计令牌，让 Figma 与代码中的颜色、字体保持一致。

02. 安装

主要包

$ pnpm add @cloudflare/kumo COPY

对等依赖 (Peer Dependencies)

$ pnpm add react react-dom @phosphor-icons/react COPY

可选 peer：echarts（Chart）· zod（AI Schemas）

03. 使用方法

基础引用

import { Button, Input, Dialog } from "@cloudflare/kumo";
import "@cloudflare/kumo/styles";

Tailwind v4 项目

Tailwind 默认不扫描 node_modules，需要在 CSS 中声明 @source，并保证 Kumo 样式先于 tailwindcss 导入。

@source "../node_modules/@cloudflare/kumo/dist/**/*.{js,jsx,ts,tsx}";
@import "@cloudflare/kumo/styles/tailwind";
@import "tailwindcss";

非 Tailwind 项目

使用预编译的 standalone 样式，包含组件所需的全部工具类与动画。

import "@cloudflare/kumo/styles/standalone";

精细导入 (Tree-Shaking)

import { Button } from "@cloudflare/kumo/components/button";

Base UI 原语

Kumo 重新导出了所有 Base UI 原语以支持高级用例：

import { Popover } from "@cloudflare/kumo/primitives/popover";

Blocks（通过 CLI 安装）

Blocks 是组合多个组件的高层页面区块，不会从包入口导出；使用 CLI 初始化配置并安装到项目。

$ npx @cloudflare/kumo init
$ npx @cloudflare/kumo add PageHeader

04. 命令行工具 (CLI)

CLI 现在同时负责组件文档、Blocks 分发、令牌迁移与 AI 指南输出。

# 初始化 kumo.json（Blocks 配置）

$ npx @cloudflare/kumo init COPY

# 列出可安装的 Blocks

$ npx @cloudflare/kumo blocks COPY

# 安装 Block 到项目（例如 PageHeader）

$ npx @cloudflare/kumo add PageHeader COPY

# 列出所有组件

$ npx @cloudflare/kumo ls COPY

# 获取特定组件文档（例如 Button）

$ npx @cloudflare/kumo doc Button COPY

# 获取所有文档

$ npx @cloudflare/kumo docs COPY

# 输出 AI 使用指南

$ npx @cloudflare/kumo ai COPY

# 导出令牌重命名映射

$ npx @cloudflare/kumo migrate --classes COPY

05. 开发指南

快速开始

$ pnpm install

$ pnpm dev // port 4321

$ pnpm lint

$ pnpm typecheck

$ pnpm --filter @cloudflare/kumo test

创建新组件

$ pnpm --filter @cloudflare/kumo new:component

Figma 插件

$ pnpm --filter @cloudflare/kumo-figma build

// Figma → Plugins → Import plugin from manifest
